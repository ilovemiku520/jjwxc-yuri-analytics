# 晋江作者 V 点击导出助手

仅用于作品作者本人从其有权访问的晋江作者后台页面导出最小化 V 章节点击统计。

1. 解压扩展包，在 Chrome/Edge 扩展管理页启用开发者模式。
2. 选择“加载已解压的扩展程序”，选中本目录。
3. 作者本人登录 `my.jjwxc.net`，打开包含完整 V 章节点击/订阅统计的作品页面并刷新一次。
4. 点击扩展并确认授权声明，在每个分页点击“收集当前页”；可以关闭页面或重启浏览器后继续。
5. 全部页面收集完成后点击“导出已收集数据”，扩展会按作品 ID + 章节 ID 合并去重。
6. 在项目网站“真实样本候选 → 作者授权 V 点击导入”上传 JSON。

扩展不会读取登录凭据、Cookie、正文、章节标题、内容提要或读者身份，不会自动翻页或调用隐藏接口。
最小记录只暂存在浏览器本机，24 小时后自动过期，最多 50,000 条；刷新页面后再次收集会用最新点击数更新同一章节。导出后暂存不会自动删除，确认文件可用后可手动清空。
若后台表格使用缩写点击值（例如“1.2 万”）而不是精确整数，扩展会拒绝导出，避免伪精确数据。
